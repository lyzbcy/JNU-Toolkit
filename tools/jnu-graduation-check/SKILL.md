# 江南大学毕设核验

## 进入系统

使用可操作本人浏览器的工具，例如连接 Edge 的 kimi-webbridge。优先打开 [e江南门户](https://e.jiangnan.edu.cn/)，选择「应用」→「AI智鼋教务平台」→「毕业设计（论文）」。官方入口调整说明：https://jwc.jiangnan.edu.cn/info/1003/7828.htm 。也可打开学校官方毕设入口 https://bysj.jiangnan.edu.cn/bysj/Index.aspx 。校外可能跳转至校园 WebVPN（https://webvpn.jiangnan.edu.cn/）。

- 复用本人合法登录态；遇扫码、短信或多因素认证，让本人在官方页面完成。
- e江南门户与网上办事大厅是不同页面；大厅登录成功不代表已进入教务平台。门户可能把应用列表嵌在 iframe 内，先读取框架内容；如点击应用后没有跳转，用实际可见元素的真实鼠标操作，并检查新打开的标签页。
- 校外若智鼋和毕设都出现 WebVPN 重定向循环，说明尚未读取到目标系统，不等于账号或课题异常。可由本人处理该站登录态，或使用学校提供的校园网/官方 VPN，再进系统。
- 若校园资源 WebVPN 持续不可用，学校还有独立的远程接入 VPN（EasyConnect）：https://vpn.jiangnan.edu.cn/ ，见[官方使用说明](https://nic.jiangnan.edu.cn/info/1019/3258.htm)。由本人安装并认证，连接成功后再打开官方毕设入口；不要在 Skill 中保存凭据或替用户调整全局网络设置。
- 认证后确认进入学生工作区，而非仅看到公开首页。若 WebVPN 出现 ERR_TOO_MANY_REDIRECTS，获本人授权后可点错误页「删除 Cookie」仅清理该站 Cookie，随后回读 WebVPN 资源站点和本人身份，重新打开智鼋；此方法已有实测恢复记录。不清理其他站点或全局浏览数据。若仍异常则走官方备用路线，不能推断没有课题。
- 智鼋入口打开后点「毕业设计（论文）」卡片（不是收藏按钮）；新标签页出现毕设公开首页时点「统一身份认证登录」。等待学生工作区出现本人姓名及角色「学生」。
- 不保存账号密码、短信码、Cookie、会话 URL、个人截图到公开仓库。

## 核验选题

1. 在首页读取选题及其他阶段进度、系统起止窗口。主页正文可能在 iframe 主框架内，使用框架读取或可见页面操作。
2. 左侧「流程管理」→「我的课题」，读取课题标题、导师和选题状态；点击课题标题打开详情，核对性质、来源、类型、学生归属及两级审核结果。字段未显示就标记未核验，不从样例推断。
3. 「暂无课题信息」只在成功进入本人学生工作区且读取到这一提示时成立；首页显示「未进行」不能单独证明课题缺失。
4. 导师指定课题与学生盲选课题是不同流程。已有指定课题时不盲选；若页面明确要求确认，向本人说明实际状态和待办，不自动变更或确认选题。
5. 首页「选题 已完成」且本人课题列表有课题、详情学生与导师匹配、审核通过，可报告已完成；不要将列表的「课题申报已完成」单独误判为需要另行确认。结果要区分已完成、待确认、无课题、认证失败、字段未核验；截图或文字回执仅留在本人私有工作区。

## 后续阶段

按首页实际窗口核查任务书、开题报告、论文初稿、定稿和答辩进度，只读现有条目。当前年度学校、学院及导师通知优先，历史日期不能写成通用截止。只有真实页面表明已审核或已提交，才标记对应状态；审阅材料、系统提交是不同状态。本版本不实现提交或材料代写。

输出：核查时间、当前阶段、课题核对结果、真实截止、待办与阻塞。避免公开用户身份、课题、导师等个人记录。
