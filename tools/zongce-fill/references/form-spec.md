# 《本科生综测个人加分项信息统计表》结构规格

模板文件：`assets/本科生综测个人加分项信息统计表（空白模板）.xlsx`
结构版本：2025-2026 学年（学院下发版）。若模板结构与本文件不符（如列位移），以实际模板为准并更新本文件。

## 总体

- 8 个 sheet：`Sheet1`（隐藏，竞赛目录）、`基础分`、`加分项-竞赛`、`加分项-论文著作专利`、`加分项-社会实践`、`加分项-学生事务`、`加分项-文体志愿类`、`加分项-其他`。
- 各 sheet 第 1-2 行（基础分/文体志愿为 1-3 行）是标题与表头，**禁止改动**。
- 模板自带浅色示例行（"例 / XXX / 45992"等），脚本写入时会先清空示例再写真实数据。
- 所有带下拉的列必须写入与下拉完全一致的字符串（含空格、引号样式），脚本从工作簿自身的校验规则读取合法值，不要硬编码。

## Sheet1（隐藏，勿动）

A 列竞赛全称，B 列对应级别（A1/A2/A3/B1/B2）。约 194 项，是学校学科竞赛目录。竞赛 sheet 的"竞赛全称"与"竞赛级别"都以此为准。

## 基础分（首条数据行 = 4）

| 列 | 字段 | 说明 |
|---|---|---|
| A | 学号 | |
| B | 姓名 | |
| C | 第二课堂学时 | 数字，上限 40 |

## 加分项-社会实践（双区结构！）

**实践区**（首条数据行 = 3，写到第 30 行为止）：

| 列 | 字段 | 下拉/约束 |
|---|---|---|
| A | 团队项目名称 | 自由文本 |
| B | 项目类别 | 省级以上重点团队 / 校级重点团队 / 院级重点团队 / 院级一般团队 |
| C | 团队任职 | 队长 / 队员 / 个人参与社会实践 |
| D | 社会实践描述 | 必填 50-100 字 |
| E | 应得分数 | |

**第 31 行 = 大创分区横幅**（合并 A31:E31 的黄色提示条，说明大创区用法；发放模板已内置，脚本写入时跳过此行，校验器识别含"大创"的横幅行自动止于 30 行——旧版无横幅模板同样兼容）。

**大创区**（从第 32 行开始，模板在此行起才给 A 列下拉）：

| 列 | 字段 | 下拉/约束 |
|---|---|---|
| A | 大创级别 | 国家级大创创新项目 / 国家级大创创业项目 / 省级大创创新项目 / 省级大创创业项目 / 校级大创 / 院级大创 |
| B | （大创不用） | 留空 |
| C | 任职 | 队长 / 队员 |
| D | 项目名称+结题情况 | 如"XXX项目（已结题通过）" |
| E | 应得分数 | 结题通过才有分 |

⚠️ 大创区 B 列下拉是实践区的团队类别选项，对大创无意义，务必留空，否则校验会当成实践区数据。

## 产出物命名规范

- 填好的表：`【学号】【姓名】本科生综测个人加分项信息统计表.xlsx`（如 `【1193230419】【余恩泽】本科生综测个人加分项信息统计表.xlsx`）
- 个人文件夹：`【学号】【姓名】/`，内含上表 + `【学号】【姓名】佐证材料/`
- 佐证文件命名：`类别-项目名.扩展名`（如 `竞赛-数学建模省一.jpg`、`证书-CET6.jpg`）
- 最终压缩包：`【学号】【姓名】综测材料.zip`
